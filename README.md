# 🌐 Website UI Clones Collection

This repository contains a collection of **6 popular website UI clones** built using **HTML & CSS only**.  
The goal of these projects was to improve frontend development skills by replicating real-world website designs.

---

## 🚀 Tech Stack
- HTML5
- CSS3
- Responsive Design (Flexbox, Grid)

---

## 📂 Projects Included

### 🚗 Tesla Clone
- Pixel-perfect UI inspired by Tesla's official website
- Focused on clean layout and modern design

🔗 Live Demo: https://teslaclone111.netlify.app/
